#   pip install -r requirements.txt

# Ranges rather than exact pins, deliberately: the exact pins this file used to
# carry had no wheels for Python 3.13 and the install failed outright. Each line
# below is bounded to the current major version, so pip picks a build that
# exists for whatever Python you are on (3.10 through 3.13 all work).
